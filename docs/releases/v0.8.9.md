# PaperLocale 0.8.9

这一版优先用首页出版信息识别期刊。PDF 首页出现独立的本刊 DOI、专属出版网址或正式刊头时，程序优先使用这些证据。作者单位或正文提到的 *Atmospheric Research* 不再覆盖明确的 *Atmospheric Chemistry and Physics* 刊头。

- **新增八种期刊。** 新版加入 *Atmospheric Chemistry and Physics*、*Global Biogeochemical Cycles*、*Philosophical Transactions of the Royal Society B: Biological Sciences*、*Ecological Monographs*、*Australian Journal of Botany*、*Global Change Biology*、*Diversity and Distributions* 和 *Global Change Biology Communications*。内置期刊规则共 39 种。
- **按原阅读顺序翻译跨栏摘要。** Royal Society 期刊中由底色分隔的两栏摘要可以连成一个译段，续页的作者单位和 ORCID 名录保留原样。
- **根据实际栏位区分摘要、出版信息和书目。** 支持 *Global Change Biology* 首页右栏摘要及 *Australian Journal of Botany* 跨页摘要。*Global Change Biology* 名录中的作者姓名、ORCID 徽标和两个对应链接保持原位。程序核实编号框开头的通讯作者说明与后续名单的边界，把首行译文排入原位置。*Ecological Monographs* 和 *Australian Journal of Botany* 的多页书目保留原文。
- **减少标题与跨栏正文超框。** 当小标题超出原框且括号内逐字重复整条英文原文时，程序核实标题身份，并在保留科学标记和通过内容检查的前提下重排。跨栏正文无法按原比例排入时，程序根据原框实际可用宽度重新分行，保留引文和科学锚点。
- **保留原 PDF 的行内符号与引文。** 程序核实字形后恢复源文件中的度数、乘除符号、叠印重音及误编码的微符号，保留真实引文中的软连字符，并翻译作者与年份之后明确属于正文的解释。单位校验识别“每年的秒数”“每天的秒数”等中文表达，也能识别表示时间顺序的“第二年”。
- **跨行数据字段可直接复制。** 同一段内被断行拆开的多段下划线字段按原顺序拼接，例如 `GPP_DT_VUT_REF`。译文需保留完整的字段名及出现次数。
- **旋转图注可在原方向阅读。** 当原 PDF 的文字方向、位置和图像范围能确认旋转图注与图件独立时，程序在图注原来的位置及方向写入译文，并检查图件和其他保护内容。

## 安装

在 macOS 13 或更新版本上，下载并完整解压 `PaperLocale-0.8.9-macOS-universal2.zip`。使用翻译功能前运行随附的 `Install PaperLocale CLI.command` 安装同版本 CLI。App 包含 Apple Silicon 和 Intel 二进制，使用 ad-hoc 签名。[macOS 安装与阅读说明](https://github.com/hazugi2004/paperlocale/blob/v0.8.9/macos/README.md)

也可在 Python 3.10–3.13 的虚拟环境中安装。

```bash
python -m pip install "paperlocale[layout]==0.8.9"
paperlocale --version
paperlocale domain-check atmospheric-science
```
