# PaperLocale 0.4.3

0.4.3 修复正式期刊双栏参考文献边界、字体连字匹配及中文修复文字换行校验，
并为一条 `run` 命令提供显式、有界的矢量恢复选项。

```bash
paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model gpt-6-astra --reasoning-effort low \
  --domain atmospheric-science --unattended --restore-source-vectors
```

`--restore-source-vectors` 只处理当前哈希绑定 QA 中确认的矢量减少页面。
若存在其他错误，不执行恢复；一次恢复后重新执行完整 QA，仍失败即停止。
修复复用既有备份、修复链和回滚能力，不重新调用已经完成的翻译。

成功结果仍为 `qa_generated`。标题、公式说明、图注和参考文献仍须逐页复核，
发现残缺或重叠时使用受控修复入口处理后重新 QA，再显式 `accept`。
新参考文献算法不会修改旧运行中已经绑定的映射和历史。

验证包括合成双栏文献边界、连字与真实单词边界、真实 PDF 矢量失败/恢复/断点
复用、混合错误停止、最多一次恢复，以及中文换行校验。发布前完整测试与真实
14 页论文验收证据记录于本次发布检查点；用户文献不进入仓库或发布附件。
