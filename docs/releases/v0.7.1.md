# PaperLocale 0.7.1

## 正文识别与公式保留

本次修复来自一篇 13 页真实论文：0.7.0 把白底白字的旋转边缘字符串当成旋转正文，因而在翻译前停止。现在按 PDF 绘制状态及实际像素识别不可见文字；白字深色背景和真正可见的旋转正文仍保持原有检查。

出版社的数学字体还可能将括号、绝对值线编码成普通字母或控制字符，并把变量、下标、运算符和函数拆成不同字体。现在保留这些已识别公式的原字形，包括统计检验关系和标准差函数；断行的斜体普通词仍交给翻译器。

个别 Type1/CFF 字体的整体字框远大于真实字形，导致删除下一行英文时误伤上一行公式。工作副本按子集真实字形收紧异常字框，逐页验证画面完全不变，写出前恢复原始字体流。原 PDF 不被改写。

## 原区域排版

中文排字可利用原正文已有的行间留白。同一基线上被两端对齐拆开的普通词共用连续区域；邻段按实际文字避让，避免把其外框中的空白误判为占用。字号、固定引用和公式位置保持不变；不能完整容纳或保护检查失败时仍保存断点，不生成缺段候选。

## 色彩与保护核验

保留 PDF 隐式默认色彩空间，避免删除正文时改变引用的蓝色；隔离保护区域恢复包含原字形边缘。固定字形的核验蒙版由原 CFF 字体程序按原坐标绘制，区分真正的公式墨迹与外框内的空白。源字形身份检查、正文外像素检查和全译文回读继续保留。

## 验证与边界

- 230 项本地测试通过，包含不可见文字与可见反例、自有 CFF 字体、数学混合编码、下标、统计表达式、同基线碎片及邻段几何回归。
- 真实论文运行正常退出：13 页、33 个逻辑翻译组、612 个保护区域；正文外区域在 144 dpi 下逐像素一致，全部译文回读存在，机器 QA 错误和警告均为 0。
- 259 个公式/锚点区域均可用原 CFF 字体绘制字形蒙版核验。288 dpi 下，非正文相交字形像素与原稿完全相同；本例仅 1 个正文/锚点墨迹相交像素，严格比对已移除待译正文且尚未插入中文的验证层。未支持的字体继续按原区域严格核验，不使用颜色容差。
- 已进行全部 13 页的模型视觉复核，并放大检查第 4、9、10 页公式；图表刻度、图注、公式和文献保留。中文在固定引用/公式之间仍会出现较多空隙与不均匀断行，尤其第 4、9、10 页，不能视为精排效果。
- 此次输出状态为 `qa_generated`，没有代用户执行人工 `accept`。上述机器和模型检查不等于人工验收。
- 自动分类仍受 PDF 编码和版式限制，不能保证任意论文都能完成。没有科学事实删减、字号缩小或保护门禁放宽。
- 不公开原论文、译文、字体、认证信息或运行缓存。测试 PDF 均由测试自行生成。
- `accept` 仍要求人工逐页验收；模型视觉复核不冒充人工批准。

## 使用

```bash
python -m pip install "paperlocale[layout]==0.7.1"
paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model YOUR_MODEL --reasoning-effort medium
```

需安装 Poppler。已有运行的版面计划绑定源文和锚点；识别结果改变时应新建运行，不能手改旧计划复用不匹配译文。
