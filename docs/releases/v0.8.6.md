# PaperLocale 0.8.6

macOS 应用新增独立 PDF 阅读窗口。可并排查看原文和译文，按页定位段落和机器检查提示，在核对后明确确认并保存当前版本。

- **PDF 阅读和译后核对。** 在阅读器中按需展开翻译设置。候选生成后可对照原译文，查看本轮翻译覆盖范围和检查结果。翻译和机器检查完成后，人工验收仍需由复核者确认。
- **人工修订。** 按页选择具体区块，查看原文、当前译文和受保护内容。先检查拟采用的译文，再应用到对应区块。修订后的候选重新排版并运行 PDF 检查，经过人工核对后才能作为新版本验收。
- **大气科学术语库。** 新建英译简中任务默认加载 2.0.0，共有 760 条术语。已绑定词库版本的断点按记录续跑。 [词库来源和规则](../DOMAIN_PACKS.zh-CN.md)

## macOS 安装

下载并完整解压 `PaperLocale-0.8.6-macOS-universal2.zip`，运行同目录的 `Install PaperLocale CLI.command`，再打开 `PaperLocale.app`。脚本安装压缩包附带的 0.8.6 wheel，App 默认使用这套 CLI。需要 macOS 13 或更新版本、Python 3.10–3.13、Poppler，以及所选翻译服务的登录或密钥。应用包含 Apple Silicon 和 Intel 二进制，使用 ad-hoc 签名。 [macOS 安装与阅读说明](../../macos/README.md)

## 命令行安装

在 Python 虚拟环境中执行以下命令。

```bash
python -m pip install "paperlocale[layout]==0.8.6"
paperlocale --version
paperlocale domain-check atmospheric-science
```

词库随 CLI 安装。人工修订、验收和另存可分别使用 `paperlocale manual-revision`、`paperlocale accept` 和 `paperlocale export`。
