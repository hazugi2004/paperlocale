# PaperLocale 0.8.1

本版是 0.8 系列首个公开发行，包含 [0.8.0 的期刊适配、源版面修复和 App 更新](v0.8.0.md)，并补齐翻译校验失败的直接诊断。

- 弹窗与 CLI 显示具体片段编号、PDF 页码、逐条失败规则、原文和本次失败译文。
- 数字、缩写和单位缺失显示缺少的标记及其原文要求次数、译文实际次数。公式、网址、样式和数值单位配对显示对应差异。
- PDF 可读原文与实际校验的 `{vN}` 占位符原文同时保留，方便核对固定公式/引用锚点。不会把这些编号直接当成论文的真实数值。
- 已纠正的首轮错误只保留在重试历史中，不混入本次失败规则；失效缓存和版面精炼失败也携带当前候选与原因。
- 旧错误报告仍可打开；升级后新产生的报告才包含新增证据。诊断不会重新调用模型或修改合格缓存。

例如原文两次出现 `CDHE`、译文一次时，会显示 `abbreviation 标记缺失`、缺少一次、要求两次和实际一次。该规则要求保留缩写字面标记；此诊断本身不裁定中文展开译法是否语义等价，也不会放宽校验。

回归覆盖首轮停止、定向重试、缓存失败、固定锚点、旧报告兼容以及无关错误不得串入旧失败记录。源版面预检及人工验收边界沿用 0.8.0 说明。
