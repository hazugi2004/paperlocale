# PaperLocale 0.5.3

修复双栏参考文献的跨栏作者名单续行识别：左栏末尾为 `Aguilar,`、右栏从 `E., Brunet, M.` 继续时，旧规则要求右栏以姓氏开头，导致漏掉右栏上半段书目并触发越界保护。

新规则同时要求左栏标题后的作者名单以逗号结尾，以及右栏“名字缩写 + 下一个姓氏和缩写”的证据；重复期刊页脚不参与末行判断。普通出版商续文仍被排除，正文越界保护、原子备份和 QA 门禁保持不变。

148 项测试通过，包含跨栏续行、出版商反例及重复页脚，检查恢复区域像素和区域外文字。实际失败论文从 119 段已完成译文断点续跑，不重新请求翻译模型。无人值守结果仍为待视觉验收的候选 PDF；本补丁不保证所有未知版式均不会失败。

python -m pip install "paperlocale[layout]==0.5.3"
