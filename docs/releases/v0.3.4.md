# PaperLocale v0.3.4

v0.3.4 把第三个真实翻译 Provider `qwen-mt` 正式纳入公共流水线，
并将一次真实论文翻译中暴露的批处理、参考文献识别和标记保护问题
收敛为不依赖特定论文的通用实现。

## 用户可见能力

- 新增 `--provider qwen-mt`，支持阿里云百炼 Qwen-MT 专用翻译模型；
- 语言代码、学科提示和术语干预均来自当前 DomainPack，不再内置第 13 篇
  论文的地名、阶段或主题特例；
- Qwen-MT 每次只收到一个源片段，每条合格译文立即原子写入断点，
  调用中断后不重复消耗已验收片段；
- `paperlocale --version` 可直接核对命令行版本，新运行清单增加
  `paperlocale_version`。

## 泛化与安全边界

- 公式占位符和样式标记在发送前换成可逆保护标记，响应删除任一标记时
  直接失败；不根据译文中某个缩写的首次出现位置猜测回填；
- API Key 只从环境变量读取并放入 Authorization header，不记录在请求正文、
  运行清单或 Provider 溯源中；远程端点必须使用 HTTPS；
- 术语表只对当前片段实际命中的条目进行干预；`compound hot-dry event`
  作为可复用词序变体收入大气科学领域包；
- 连接临时断开最多进行两次短重试；HTTP 业务错误仍立即失败并保留诊断。

## 真实运行反向校准

- 修复 `paperlocale run` 未把 `--max-segments` 和 `--max-characters` 传入
  翻译阶段的问题；
- URL/DOI 门禁可确定性处理 `doi.org/` 与 DOI 之间的 PDF 断行，以及
  网址后紧邻的中文文本；缩写门禁可处理连字符断行和正文粘连；
- 未将特定 PDF 中的错误公式字形当成全局数字改写规则，避免损坏其他论文
  的真实分数、比例或时间；
- 参考文献标题和区域改用 PDF 可见文本行识别，修复 PyMuPDF 把标题与
  整页书目合并为一个文本块时的整区漏检。

## 验证边界

- 88 项不联网单元测试在项目支持的 PyMuPDF 1.25.2 环境全部通过；
- 新回归覆盖 Qwen 请求结构、密钥不入正文、临时断连、保护标记恢复/删除、
  Provider 批处理上限、评估入口、同块参考文献标题、行号边界、URL/DOI 与缩写；
- 标签构建在安装确切 wheel 后核对 Git 标签、包元数据、模块版本和
  `paperlocale --version`，然后再运行领域包和 `[layout]` 依赖求解门禁。

真实论文、完整译本、本地运行目录和 API 凭据均未纳入仓库或发行包。
参考文献默认策略仍为 `preserve`，机器 QA 后仍必须逐页人工验收。
