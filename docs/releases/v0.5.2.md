# PaperLocale 0.5.2

修复书目换行以四位年份开头时被误判为编号章节的问题。例如 `2017 Multivariate statistical modelling of compound events` 曾使参考文献区域提前结束，导致自动恢复触发“书目越界涉及源页正文”。现在四位年份不会匹配编号章节，书目区域能继续覆盖后续条目与跨页内容。

保留真正编号章节边界、正文越界保护、原子备份和机器 QA 门禁。回归用自有 PDF 验证年份续行、跨页书目、重叠译文、后续 Figures 章节与恢复像素；实际失败论文从已完成的翻译断点续跑，无需重新请求模型。

实际续跑还发现源 PDF 将软蒙版同时列为独立图片资源：译文清理该资源后，显示图片并未减少。QA 现按内容流中实际图片放置计数，包含嵌套 Form 和重复放置；回归同时保留真实缺图报错测试。147 项本地测试通过。

此版本针对已确认的年份误判，不保证未知版式或网络、模型内容不会发生其它失败。无人值守输出仍是待视觉验收的候选 PDF。

```bash
python -m pip install "paperlocale[layout]==0.5.2"
```
