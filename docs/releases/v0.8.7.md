# PaperLocale 0.8.7

0.8.7 支持通过 OpenAI 官方 API 翻译论文，并对保版译稿的绘制流进行无损压缩。

- **OpenAI 官方 API。** 在 macOS 应用的「翻译设置」选择「OpenAI API（独立计费）」并填写项目可用的模型和 API 密钥。CLI 使用 `--provider openai-api --model MODEL`，从 `OPENAI_API_KEY` 读取密钥。程序逐批校验并保存译文，常规请求最多 10 段、4,000 个源文字符，超长单段保持完整。
- **更小的译稿。** 压缩保版译稿的绘制流并写入当前 PDF 版本。两份旧译稿在同一排版结果下分别缩小约 76% 和 84%，逐页渲染、可搜索文字和链接保持一致。
- **公式和引文。** 修复复杂行内公式附近的原文顺序、跨页引文的排版以及附录符号与释义的对应关系。十篇回归样本均从空译文缓存一次启动生成候选 PDF，全部通过机器检查。全文仍可在阅读器中逐页核对。

## 安装

在 macOS 13 或更新版本上，下载并完整解压 `PaperLocale-0.8.7-macOS-universal2.zip`。使用翻译功能前运行随附的 `Install PaperLocale CLI.command` 安装同版本 CLI。应用包含 Apple Silicon 和 Intel 二进制，使用 ad-hoc 签名。[macOS 安装与阅读说明](../../macos/README.md)

也可在 Python 3.10–3.13 的虚拟环境中安装。

```bash
python -m pip install "paperlocale[layout]==0.8.7"
paperlocale --version
paperlocale domain-check atmospheric-science
```
