# 0.8.0：期刊适配、交互修复与源版面鲁棒性

## 自动期刊适配

默认 paragraph 模式读取源 PDF 元数据、前三页刊名/DOI，记录命中证据及页码。未知或不能唯一确定的来源保留通用规则，不按文件名猜期刊。补充材料仅在同目录正文标题能与附件标题核对一致时继承期刊。旧断点按其原自动计划复核，不静默重建缓存。

可运行 `paperlocale journal-info paper.pdf` 查看识别依据。版面规则在 `layout_plan.json` 的 `journal` 和各块 `preserve_reason` 中可查。

不同出版社共用其版式家族规则：ASCE、AGU/Wiley、PNAS、Science、AMS 的边缘下载/版权标记，Nature 排印字符，Elsevier 出版导航，Frontiers 稿件信息，以及已识别机构/下载封面。所有规则结合具体文字和页面位置；只保留有证据的出版辅助信息。正文、公式、图表仍走既有视觉检测和科学内容门禁，不把所有旋转文字一概跳过。

## 不改源码的错误处理

段落级错误显示原文、从 1 开始的 **PDF 物理页码**、坐标和片段 ID。字体符号以实际提取/核验结果记录，不猜测未知字形。服务请求失败给出请求批次上下文；只有页面线索的错误明确标为“尚未定位到句”。文件/服务级错误可能没有原句，不编造定位。

终端交互运行默认显示字母菜单；也可显式加 `--interactive-errors`。`--no-interactive-errors` 保留脚本运行方式，`--unattended`、`--no-contract-repair` 默认不主动询问，以保持既有无人值守和首错停止行为。

| 字母 | 适用情形与动作 |
| --- | --- |
| r | 从断点重试一次，复用已通过缓存；模型请求可能计费 |
| t | 内容或排版失败：仅清除失败片段的译文/排版精炼缓存，重新翻译 |
| f | 排版溢出：仅把失败段落的字号下限降低 10%，最低 6 pt；仍须完整排入且通过核验 |
| s | 内容/排版失败：保留失败片段原文；提取阶段可保留指定异常块，不改写科学符号 |
| b | 存在修复快照时，回退上一修复及其后续尝试；回退后不自动调用模型 |
| q | 保存当前断点，退出/关闭弹窗 |

只展示当前错误可用的动作。修复通过现有流程重新尝试，失败不会变成成功。每次修复前保存本运行的快照；回退前核对备份完整性，`repair_audit.jsonl` 保留操作历史。错误 ID 与源 PDF 摘要防止旧菜单误操作新的任务。提取分组已进入模型翻译后，不允许再改变块身份。

App 在失败后弹出同一组后端动作，显示原文及页码，并可打开源 PDF。无需在弹窗输入 CLI 命令。外部脚本可使用 `paperlocale repair-choice --run-dir RUN --error-id ID --choice s`，此命令只应用选项，不启动模型；随后用原来的 run 命令继续。

选择跳过后，`translation_coverage.json` 与 `preservation_report.json` 记录未翻译项并标为非完整翻译。原文对象保留，机器 QA 继续检查候选；机器 QA 与人工验收仍分开。回退范围是运行目录，不包括已导出 PDF、源论文或外部文件。

## macOS

使用用户提供的奶龙图片作为图标、奶蛋图片作为滚动进度指示。进度按提取、翻译片段计数、排版、写入、QA、导出推进，是阶段进度，不是假定的剩余时间。系统开启减少动态效果时关闭旋转动画。

支持拖入一个本地 PDF；文件选择和拖放走同一个校验入口，运行中禁止换源。仍支持选择翻译服务、模型、推理档位和保存位置。

## 验证边界

期刊识别、版面预检、离线回归、App 编译和实际窗口检查不等于 52 份 PDF 全文翻译或人工视觉验收。源 PDF、完整抽取文本、运行缓存和预检证据仅留在被忽略的本机技术工作区，不随软件分发。

macOS 构建包含 arm64 与 x86_64，通过 ad-hoc 签名验证；实际运行测试在 Apple Silicon 上，未做 Intel 实机验证，也未做 Apple 公证。

本地完整回归：354 项通过；包括真实 PDF 跳过后的原文位置核验和机器 QA、备份损坏拒绝回退、Swift NSItemProvider 拖放与分块 UTF-8 进度解析。App 弹窗通过隔离测试后端实测修复与回退，不调用付费模型。

## 源版面兼容性修复

修复原字体资源绑定（Type 1/PFA、CFF、CID-CFF、TrueType）、重复空白与子集数学编码、合字及组合重音删除、公式分母/上下限边界、横置页面坐标与链接、明确标记的背景水印，以及首页出版信息图片误报。数学语义仅依据已核验原轮廓恢复；未知非空字形仍报错。

出版社的 ActualText 内部公式 ID、零宽空间及合字辅助标签不再替代真实字形。整页 Contents 数组作为完整绘制程序解析，避免文字操作数与操作符跨流时丢行。模型请求前新增 144 dpi 原页像素对照，并实际验证正文删除和固定字符保留；已知源处理缺陷先停止，不先消耗翻译请求。

本地 52 份来源 PDF 中原先失败的 26 份已逐篇分类修复；同一冻结实现全库 **52/52** 通过源版面预检。26 份共 **4,969** 个行内锚点完成实际写入、重开和字形核验；原 PDF 哈希不变。正文覆盖变化另行复核，不以跳过正文换取通过。真实论文及全文证据不随发行公开。

旧运行的布局计划和译文缓存不原地改写。需要重新分析旧计划时，创建新运行目录，并用 `--import-cache-from OLD_RUN` 显式复用源文及锚点身份符合要求的缓存。上述验证是源版面兼容性证据，不是 52 篇全文翻译、最终排版或人工验收；网络、模型输出及未知 PDF 结构仍可能产生新问题。
