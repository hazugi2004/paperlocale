# PaperLocale 0.8.4

新建英译中任务默认使用内置大气科学术语库 2.0.0。词表共有 760 条英文词条，其中 262 条规定译名，498 条提供语境建议，覆盖天气与动力气象、边界层、云与辐射、大气化学、气候极端事件、陆气通量、观测遥感和数值预报。词表来源和专业用法见[领域包指南](../DOMAIN_PACKS.zh-CN.md)。

翻译请求仅携带当前段落命中的词条，匹配考虑大小写、常见连字符和受支持的复数形式。必用译名进入译文校验，Qwen-MT 同时通过术语和翻译记忆参数接收相应词条。已经绑定到 1.1.0 的任务按原词库续跑。要让同一份 PDF 使用 2.0.0，可新建运行并显式导入旧缓存，PaperLocale 会按新规则逐段复核可复用的译文。

## macOS

需要 macOS 13 或更新版本。解压 `PaperLocale-0.8.4-macOS-universal2.zip` 后先运行同目录的 `Install PaperLocale CLI.command`，再打开 `PaperLocale.app`。脚本从下载包内安装 0.8.4 CLI，App 默认调用该安装。仍需 Python 3.10–3.13、Poppler、依赖下载所需的网络，以及所选翻译服务的登录或密钥。应用包含 Apple Silicon 和 Intel 二进制，使用 ad-hoc 签名。完整步骤见[macOS 安装说明](../macos/README.md)。

## 命令行

在 Python 虚拟环境中安装并检查版本。

```bash
python -m pip install "paperlocale[layout]==0.8.4"
paperlocale --version
paperlocale domain-check atmospheric-science
```

词库随 CLI 自动安装。使用 macOS 下载包时，也可以将同包的 wheel 安装到自己的 Python 虚拟环境。
