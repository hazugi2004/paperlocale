# PaperLocale v0.4.1

v0.4.1 是由 15–34 篇真实复合干热文献并行试运行触发的最小热修复。
它不改变翻译 Provider、内容合同、参考文献默认 `preserve` 或人工验收边界。

## 真实失败证据

- 第 28 篇在第 9 页右栏中途开始 `References`，v0.4.0 按整页纵向区域
  收集文本，因而把左栏 4 个结果/结论片段误标为参考文献；
- 第 29 篇的 References 后还有 Acknowledgements、Author contributions、
  Publisher note 和 Creative Commons 许可证，旧区域结束策略会把其中 5 个
  长片段自动纳入 `preserve`；
- 第 30 篇的短参考文献/许可证片段同时命中安全审查，而旧版又禁止
  参考文献与透传映射重叠，导致运行无法沿公开命令闭合。

## 热修复

1. 若唯一 References 标题位于页面右半部，只在标题首页排除其左侧文本行；
   后续页仍按全宽处理，不推测其他栏结构。
2. `confirm-references` 支持重复使用 `--exclude-segment-id`；只允许排除当次
   自动匹配项，禁止同一 ID 同时补充和排除，并把排除顺序写入哈希绑定映射。
3. 片段安全摘要仍完整记录所有命中项，但已确认参考文献不再重复计入
   所需透传集合；运行清单额外记录参考文献豁免数量。

## 验证

- 97 项不联网单元测试覆盖 Codex/API、ChatGPT Web 桥接和旧映射兼容性；
- 第 28 篇真实片段回放中，4 个已知左栏正文 ID 不再自动匹配；
- 发布构建仍要求确切 wheel 的模块/元数据/CLI 版本一致、`twine check`、
  领域包检查和 `[layout]` 依赖求解。

本版本不上传或再分发任何真实论文、完整译本、网页会话或凭据。
