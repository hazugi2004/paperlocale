# PaperLocale v0.3.3

v0.3.3 为真实论文视觉验收中无法在片段层修复的文字碎裂提供一条受控、可审计的
最后修复路径，同时保留“机器 QA 后必须逐页人工验收”的边界。

## 用户可见能力

- 新增 `paperlocale apply-text-repair`，要求显式提供运行目录、从 1 开始的页码、
  PyMuPDF 矩形坐标、替换文字、本地字体文件、字号和修复说明；
- 只删除目标矩形内文字，并在同一矩形写入替换内容；不自动猜测页码、坐标、字体
  或字号；
- 接受 `rendered`、`qa_generated` 或 `accepted` 候选，但每次成功修复后都退回
  `rendered`，清除旧 QA 与人工验收绑定，强制重新执行 `qa` 和 `accept`；
- 自动备份修复前 PDF，并在 `repair_history` 保存页码、矩形、修复前后文字、说明、
  字体与子集哈希、字体字节变化、PDF 修复前后哈希及结构计数。

## 版面与字体保护

- redaction 使用透明填充，只删除文字层；图片与矢量删除选项均关闭，避免白色覆盖层
  遮住矩形内仍应可见的对象；
- 候选必须保持页数、页面尺寸、图片数量、链接数量、标注数量、非目标页文字以及
  目标矩形外文字和坐标；既有矢量数量不能减少；
- 使用 FontTools 在嵌入前只为本次替换文字生成独立字体子集，不调用会重写整份
  PDF 既有字体的全局子集化；
- 字体资源名绑定子集内容哈希，因此同一字体连续修复新增字形时不会错误复用先前的
  缺字子集；缺字、文字溢出、非有限字号、已有 redaction 标注或任一结构变化均硬
  失败，不覆盖当前候选。

- 当前主线 74 项不联网测试通过，覆盖原子备份与回滚、QA 重置、缺字、溢出、非法
  字号、已有 redaction、非目标字体不变、连续修复子集隔离及矩形内矢量可见性；

  为 22,912 字节，最终 PDF 为 19,594 字节；机器 QA 为 0 errors / 0 warnings，逐页
  对照确认中文、黑色矢量标记、表格、图片、链接、相邻正文和第二页均正常；
- 从源码构建的 wheel 在全新虚拟环境完成依赖安装、`pip check`、领域包检查及
  `apply-text-repair` 入口发现，发行元数据包含 `fonttools>=4.55`。
