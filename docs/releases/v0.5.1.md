# PaperLocale 0.5.1

Codex Provider 不再让模型复写64位片段哈希，避免漏抄字符后整批输出被拒绝。
每批使用 `s1`、`s2` 等本地短键，schema 要求所有键存在且没有额外属性；
模型只填写译文值，稳定哈希由本地程序绑定并用于原有缓存和内容检查。

响应按键解析而非按顺序配对，重复 JSON 键在解析阶段即拒绝；缺键、额外键、
非法译文类型和旧格式响应也不会被猜测或模糊修补。参考文献身份及合同修复
反馈按同一映射传入模型。其它 Provider 接口保持兼容，不切换模型、不增加
网络/模型的盲目重试，也不削弱公式、数字、术语和 PDF 验收门禁。

142项本地测试通过，包含实际错误哈希、必填schema、乱序、缺键、重复键、
反馈映射及保持原哈希的缓存续跑。实际论文从已保存的32条译文断点继续验证，
成功的批次无需重新翻译；私人PDF和运行证据不进入公开包。

```bash
python -m paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model gpt-6-astra --reasoning-effort medium \
  --domain atmospheric-science --unattended
```

本补丁解决的是 Codex 长哈希传输问题，不保证网络、模型内容或任意未知版式
不会出现其它失败。机器 QA 成功仍须逐页视觉复核后 `accept`。
