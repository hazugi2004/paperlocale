# PaperLocale v0.2.0

v0.2.0 把发布后的安全与完整性修复扩展为更适合真实用户试用的可验证工作流。

## 主要变化

- `paperlocale run` 从当前清单断点一键推进到机器 QA，翻译完成后的续跑不再要求 Provider 凭据，并始终保留显式人工 `accept`；
- PDF QA 在图片对象或矢量绘图少于原文时硬失败，并逐页记录两侧数量；
- 断点续跑核对翻译阶段记录的领域包 ID 和版本，拒绝静默更换同语言术语合同；
- `paperlocale provider-eval` 用领域包公开案例保存真实候选、参考译文和内容合同结果，不把字符串相似度伪装成语义准确率；
- README 增加由自有合成论文生成的演示 GIF；每周兼容性工作流真实运行 `pdf2zh-next` 两阶段闭环。

## 验证证据

- 37 项不联网单元测试覆盖 Python 3.10–3.13；
- 真实 `pdf2zh-next 2.9.0` 合成双栏 PDF 冒烟通过；
- 最新 QA 报告为零错误、零警告，源文与译文均为 1 个图片对象、8 次矢量绘制；
- 本机 Codex CLI 对大气科学包 5/5 案例通过内容硬合同；领域人员语义复核仍明确标记为待完成；
- wheel 与 sdist 通过 `twine check`，wheel 在隔离环境安装后可加载内置大气科学领域包。
