# PaperLocale 0.7.3

修复两篇降水论文实测暴露的问题：

- 正文列表编号被检测器误标为独立公式时，只有编号框紧贴编号且同一行后面有英文正文，才解除该错误保护。独立公式编号继续保留。
- `all-day/hour`、`wet-day/hour` 中的斜杠表示日或小时尺度，不作为 day/hour 复合单位。带数值的真实量值仍执行单位检查。
- 段落模式区分图注标题与正文中的 `Figure 5 displays`、`Figure 2a` 引用；支持罗马数字表号，防止把多条表注合并。旧 preserved 引擎保留原识别规则。

恢复已初始化的段落运行时显式传入 `--layout-mode paragraph`；已经进入 legacy 的运行不能切换引擎。修正规则后需新建运行目录，并只迁入原文完全相同、通过内容与锚点检查的译文缓存，不手改自动版面计划。

- 正文悬挂列表按独立编号分段，保留缩进；小节标题、公式之间连接词不与正文合并，短末行按完整段落排版。
- 对上标标志增加字号/基线复核，避免公式下标之后的正常正文被误保护；保留真实上标和原数学字体字形。
- 多作者名单先验证姓名结构再判断长度，保持原文而不猜测中文姓名。

- 致谢之后的明确附录标题恢复正文翻译；圆点列表保留原符号字形并分别排版，避免PDF错误Unicode映射将圆点重写成其他符号。
- 独立公式两侧说明按原位置分别翻译，同一视觉行的上下标片段自动重组；短解释不再被分配到错误公式或前页末尾。混合字号的斜体乘积、公式撇号沿用原字形。
- 两行普通字重小节标题根据原文额外行距与正文分开；字母机构上标和长机构名单保留原文。
- 图片核验统计PDF实际图片调用，不将渲染器生成的渐变临时位图误算成原生图片。正文负左侧承用原字体实际墨迹核验，邻近图形的真实改变仍拒绝。

验证：255项本地测试通过。两篇真实论文均用最终代码完成全文运行（13页/103个译文单元、16页/96个译文单元），退出状态均为0；29页QA无错误、无警告。模型逐页视觉复核通过；重生成的完全相同页面以逐像素比较承接前轮复核证据，所有变化页面直接复核。覆盖15条和4条图表注、悬挂列表、跨页段落及附录A1至A14。人工accept尚未代用户执行。

段落识别仍依赖视觉检测和几何规则，不能保证所有未知PDF首次成功。机器检查、模型视觉复核与用户人工 accept 分别记录。不公开论文、译文或缓存。
