# PaperLocale 0.8.2

本版将常见失败的诊断、原页对照、译文修订和恢复操作集中到 App 内。它仍是调用本机 CLI 的 macOS 前端，需要 Python、layout 依赖、Poppler 和所选模型服务。发行附件及安装版本以 GitHub Release 和 PyPI 的实际记录为准。

## 应用内修复

- 错误显示稳定分类、PDF 页码/区域、片段编号、原文、失败译文、规则要求与实际差异。保护区像素及回读文字差异也提供位置证据。
- 修复窗口内浏览原 PDF、跳到报错页、查看固定公式/引用标记的对应内容。可先只校验编辑，再保存合格修订并继续；校验本身不调用模型，后续排版精炼可能调用模型。
- 保存前建立快照；不合格修订不写入缓存，可回退。修订绑定源文件、领域包、版面计划和当前错误，过期报告不能改写另一轮运行。
- 源布局更新后新建运行并逐条验证导入缓存；保留原运行和模型来源。字体缺字不提供无效的缩字号修复。返回设置可以调整字体、批量大小、路径和服务参数。
- 未知 PDF 结构、未支持的字体、不可用的服务仍可能需要引擎更新或服务恢复；不能保证任意错误由用户操作即可消除。保护和内容检查不得忽略。

## 工作区

新任务默认使用 `~/paperlocale/`，App 可选择并记住工作区根目录，CLI 支持对应工作区选项。每份 PDF 用规范化源路径摘要区分同名文件。打开旧运行时恢复服务、模型和输出位置；不迁移或删除原断点。结果 PDF 保存位置与内部工作区独立配置。

## 本轮修复范围

- 共性：控制字符、数量/单位语境、长引文及网址换行、CropBox 坐标、长括号跨框、悬挂列表、独立公式开括号、带原生横线的行内分式及作者姓名碎片。
- ASCE：会员资格属于作者元信息；按已核对原字体轮廓恢复数学编码；保留旋转下载栏，并识别该版式的正文标题。
- Springer/Copernicus 实例促成的通用规则只以实际字形、位置和结构证据触发，不将整本期刊的斜体或短文本都当作公式。
- 旧计划通过修订标记沿用原提取路径；需要新规则时重新分析，禁止手工改写版面计划规避身份校验。
- 保留 PDF 原生矩形、渐变、Form 资源及页框的有效数字精度，并在完整原生字形、字体和变换证据一致时恢复受保护图表中文字的原始 TJ 间距。修复两个独立渲染器对重写数字产生不同图内像素的问题；不栅格化整页，不放宽保护阈值。
- 识别竖线分隔标题、叠放标题、附录字母数字题注、正文中的几何下标及普通字体公式。回归期中的 `100-year event` 不再被误判为年份乘事件单位。
- 恢复缓存导入时重新核对原 PDF、版面、领域、单元和缓存内容；过期导入报告不再被沿用。Qwen 已执行内部限流重试的异常不再获得额外外层重试。
- Codex 本地后端在超时和 Python 中断时清理同进程组子进程，并回收直接子进程；相对可执行路径在进入临时目录前解析。此后端要求 POSIX，未承诺回收主动脱离进程组的守护进程或无法捕获的终止信号。
- 扩展原生引用保护到同一段落的跨行与跨框引用，避免带变音符的作者姓名被交给不含该字形的中文字体。带原生横线的分式按字符结构保护分子、分母和标签，防止跨排版框拆开。

- 隔离有期刊与几何证据的首页出版侧栏，避免 `OPEN ACCESS` 误保护无标题摘要；表图内的 `References` 标签不再触发全篇书目状态，旋转页使用一致的规范坐标。旧版计划仍按其记录的提取修订验证。
- 旋转页机器 QA 按实际排版的规范源严格比较几何；规范化必须与原始源页逐像素一致，译文尺寸、裁切或方向真实变化仍失败。

## 验证与边界

本轮真实论文使用 `codex-local / gpt-6-astra / high`，覆盖双栏、密集公式、位图与矢量图、旋转整页表格、跨页表格、长段落及跨框引文。五篇完整论文共 91 页完成机器 QA、全部页面对照复核和独立 Poppler 检查；对应文件哈希与证据保存在本地任务验收报告中，论文和私有日志不随软件公开。不能把已有译文行数或机器 QA 状态单独当作完整验收。历史八篇验证和 52 篇旧版预检不代表本轮最终版本全部通过。

冻结源码的 460 项本地回归通过。正常空缓存翻译、受控服务失败后的缓存恢复、布局变化后的严格缓存导入均有验证。最终空缓存复测的翻译与 QA 完成后，首次导出因已有无关文件被安全拒绝；改用新输出名恢复成功，未重复调用模型。

五篇中 07 的 63 个图表/公式保护框在 144 dpi 下全部逐像素一致；其余论文的三个原始框差异由邻近正文/题注墨迹完整解释，保护对象墨迹无未解释差异。未使用颜色容差、整页栅格化或删除失败内容来通过检查。

长原生引文换行、局部列表行距、段落留白和标题字体/颜色仍可能与原文不同。语义检查覆盖科学术语、关键数字与代表性论证，不能替代逐句专业审校。机器 QA 和代理逐页视觉检查不自动写入用户人工验收。保留原文的图表、公式、书目与出版元信息沿用产品范围；保留原文修复产生的部分翻译须另行标识。macOS 构建为 Universal 2、ad-hoc 签名，未经 Apple 公证；本机运行验证不等于 Intel 实机验证。
