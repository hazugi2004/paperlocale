# PaperLocale 0.8.9 for macOS

打开论文后可以立即浏览原 PDF。有候选译文时，同一窗口可切换原文、译文和双栏对照。翻译和机器检查使用配套 CLI，人工验收由复核者在 App 中确认。

## 安装

1. 在 macOS 13 或更新版本上，从 [v0.8.9 GitHub Release](https://github.com/hazugi2004/paperlocale/releases/tag/v0.8.9) 下载并完整解压 `PaperLocale-0.8.9-macOS-universal2.zip`。可立即用随附的 `PaperLocale.app` 阅读 PDF。
2. 使用翻译前，先安装 Python 3.10–3.13（推荐 3.12）与 Poppler（`brew install poppler`），准备所选服务的登录或 API 密钥。双击 `Install PaperLocale CLI.command`，或在解压目录运行 `bash "./Install PaperLocale CLI.command"`。脚本安装随附的 `paperlocale-0.8.9-py3-none-any.whl`，联网下载排版依赖并检查大气科学术语库。
3. 安装后可将 `PaperLocale.app` 放入“应用程序”。应用默认使用 `~/Library/Application Support/PaperLocale/cli/0.8.9/bin/paperlocale`，终端也可直接调用此路径。若在“翻译设置”手动选择了其他 CLI，该选择只对当前发行版本有效。也可把随附的 wheel 安装到已有 Python 虚拟环境。

App 使用 ad-hoc 签名。若 macOS 阻止打开，先核对发行来源与 SHA-256，再使用系统“隐私与安全性”的“仍要打开”。[Apple 的首次打开说明](https://support.apple.com/102445)

## 阅读与联动

- 拖入单个 PDF、点击“打开 PDF…”或按 `⌘O`。原文预览可离线使用。
- 阅读区足够宽时，候选默认在右栏显示。点击或滚动相应栏后，工具栏使用该栏的页码、缩放和搜索。可关闭联动，也可用 `⌘F` 搜索当前栏。旋转和裁切导致位置无法对应时，联动只对齐页码。
- 窄窗口在原文和译文间切换并保留当前页。审校面板中标明页码的项目可直接跳转。

## 翻译与断点

新任务默认使用英译中大气科学术语库（`atmospheric-science` 2.0.0）和整篇保版。打开原 PDF 时，App 在默认工作区查找与源路径和文件哈希同时匹配的运行。新任务默认放在 `~/paperlocale/<文件名>-<源路径摘要>/`。也可以通过“打开已有运行…”选取包含 `run_manifest.json` 的目录。

继续运行会沿用清单记录的服务、模型和版面模式。服务或模型变更需要新建运行。

- 在「翻译设置」选择「OpenAI API（独立计费）」，提供 API 项目密钥，获取可选模型并选择支持结构化输出的模型。服务地址已固定。获取模型时仅向 OpenAI 查询项目的模型列表，开始翻译后才会发送待译文本。
- 兼容 API 和 Qwen-MT 使用包含版本前缀的服务地址。Codex 使用本机已登录的 CLI。
- App 内输入的密钥仅留在窗口内存。翻译进程也可使用 App 启动环境中的 `OPENAI_API_KEY`（OpenAI 官方 API）或 `PAPERLOCALE_API_KEY`（兼容 API 和 Qwen-MT）。

运行时仍可阅读原文。“诊断”可展开查看日志。翻译失败时，可以从原文定位打开修订区块。审校已生成的候选时，也可以选择当前页的译文区块。

在区块内修改有问题的译文，预览后点“采用我的修订”。图号、公式、ERA-5 等固定标识符和可核实的跨行网址以完整的锁定文本显示。通过校验后，排版使用你确认的原文字串，续跑从保存的区块读取人工修订。同一句出现多次时，可按页和位置选择要修改的那一处。“诊断”提供已有的重试与回退操作。

统计量校验会区分物理单位和原句里的统计分母。例如 `10.43 days per event-occurring summer` 对应“每个发生过事件的夏季平均 10.43 天”。遇到程序无法自动识别的分母，核对原文后可确认这一处，修订记录会保留确认依据。

## 处理异常

- 点“修复与继续”打开问题和原文。具有确定坐标的问题会在原文栏和修复窗口以荧光黄底标出。只有页码时可跳到对应页。高亮只在阅读窗口显示。
- 遇到服务授权错误时，打开翻译设置更新密钥或完成服务登录，再点“使用当前设置重试”从断点继续。
- 如果正文与受保护的公式或字形重叠，可查看被定位的区域。当修复窗口提供“保留原文并继续…”时，明确确认后会保留相应区块并继续。候选显示“部分翻译”，审校面板列出所保留的内容。
- 如果旧译文缓存和当前运行不兼容，选择“跳过旧缓存并继续”。当前运行里已通过校验的译文仍可复用。对无法唯一定位的源版面问题，可以重新分析版面。
- 如果候选已通过机器检查，但同名文件占用了保存位置，选择“解决保存问题”，再点“另选位置保存候选…”。程序会按已核对的候选版本另存，人工验收仍可独立提交。

## 检查与验收

- 可在“翻译设置”关闭自动机器检查，先预览候选。使用“运行机器检查”检查当前候选与源 PDF。审校面板显示机器错误、警告和保留原文的记录。用户跳过的译文仍标记为“部分翻译”。
- 对候选采用人工修订后，App 会生成新候选并重新进行机器检查。逐页对照后再提交这一版的人工验收。
- 机器检查通过后，逐页对照原文和候选。点“记录人工验收”，填写复核者并确认已逐页检查。保存时，配套 CLI 核对原文、候选、检查记录及保版证据，并确认候选仍是复核者刚刚审阅的版本。
- 默认导出在源 PDF 所在目录。若目标被其他文件占用，在验收窗口用“保存到…”改名或改位置，当前的机器检查结果可以继续使用。

## 构建

在安装了 Xcode Command Line Tools 的 Mac 上，用 Python 3.11 或更新版本安装 Pillow，执行 `python3 scripts/build_macos_app.py`。脚本编译 arm64 和 x86_64，生成经过 ad-hoc 签名的 Universal 2 App 和 ZIP。若源码目录上的 FinderInfo 妨碍签名，可用 `--output-dir` 指定本地构建目录。

发行构建使用 `python3 scripts/build_macos_app.py --wheel dist/paperlocale-0.8.9-py3-none-any.whl`，在 ZIP 中加入该 wheel 和 CLI 安装命令。仅构建应用时，默认使用原有的 CLI 设置或 `~/.local/bin/paperlocale`。可在虚拟环境运行 `python -m pip install ".[layout]"`，然后在“翻译设置”选择该环境的 `bin/paperlocale`。运行 `PaperLocale.app/Contents/MacOS/PaperLocale --cli-path` 可查看应用当前使用的 CLI 路径。

## 0.8.3 鲁棒性修复

修正复杂地图的图片绘制框匹配开销、文字删除时的图片资源上限、作者贡献侧栏分类、复合下标与高括号、上标引用前正文词、特殊字符网址及嵌入字体的 Unicode 检索歧义；源文结构修订保留独立版本和旧计划兼容路径。图片调用减少只有在有序资源检查和匹配的源版面像素证明共同通过时才允许。详见[发布说明](../docs/releases/v0.8.3.md)；两篇真实论文的运行证据与验收边界见[发布前鲁棒性验证记录](../docs/robustness-20261027.md)。

翻译失败弹窗和 CLI 直接显示片段编号、页码、逐条规则差异、原文及本次失败译文；详见 [更新说明](../docs/releases/v0.8.1.md)。

## 0.8.0 交互更新

支持将单个 PDF 拖入窗口。奶龙图标和奶蛋进度指示取自用户提供的图片；奶蛋随真实阶段进度移动和滚动，减少动态效果模式下不旋转。进度不是耗时预测。修复选项和跳过记录详见 [更新说明](../docs/releases/v0.8.0.md)。

如同步目录的 FinderInfo 导致签名失败，可指定本机缓存目录：`python3 scripts/build_macos_app.py --output-dir ~/Library/Caches/PaperLocale/0.8.0`。
