# PaperLocale 0.8.8

这一版修复了保版译文和修订窗口中科学标识符以及跨行网址被拆开的情况，并更新了 macOS 翻译设置和修复提示。

- **科学标识符完整保留。** 新版识别 ERA-5 这类带连字符和数字的标识符，将它们作为一个固定内容交给译文和排版流程。
- **跨行网址按一个链接处理。** 当原 PDF 的链接标注和可见文字能证明多段内容属于同一网址时，修订窗口显示完整网址。PDF 可在需要时换行，各行仍指向原网址。
- **已有断点可继续。** 修订窗口对可核实的旧拆分内容合并显示，保存时沿用旧断点的标记。新运行使用更新后的提取和排版规则。
- **更具体的提示和模型选择。** 原样提交、真实内容校验问题和排版溢出分别提示。OpenAI API 模型从项目可用列表选择。

## 安装

在 macOS 13 或更新版本上，下载并完整解压 `PaperLocale-0.8.8-macOS-universal2.zip`。使用翻译功能前运行随附的 `Install PaperLocale CLI.command` 安装同版本 CLI。App 包含 Apple Silicon 和 Intel 二进制，使用 ad-hoc 签名。[macOS 安装与阅读说明](https://github.com/hazugi2004/paperlocale/blob/v0.8.8/macos/README.md)

也可在 Python 3.10–3.13 的虚拟环境中安装。

```bash
python -m pip install "paperlocale[layout]==0.8.8"
paperlocale --version
paperlocale domain-check atmospheric-science
```
