# 0.7.4 — 2026-09-22

This patch follows the Wu (2021) BDHI translation failures. The release retains the validation limits below.

## Changes

- Resolve traced control-code spaces, multi-Unicode ligatures and truncated font names using source glyph evidence. Match duplicate font objects only when their font program and descriptor agree.
- Normalize temporary CFF and PDF descriptor metrics for safe text erasure; restore original font objects before delivery. Layout plans retain their source metrics.
- Preserve figure panel labels and fixed mathematical ink. Paragraphs wrap around actual protected ink and recheck obstacles after baseline changes. Empty obstructed lines cannot drop target text.
- Relocate links whose extracted xref is zero by matching a unique native annotation rectangle. Compare protected image pixels by pixel-center inclusion, without a color tolerance.
- Pass pure DOI text through Qwen. Separate throughput limits from account exhaustion; one bounded rate retry is not repeated by the outer recovery loop. Smooth subsequent requests using actual token usage with a local 20,000 TPM target, not an account quota guarantee.
- Remove stale marker instructions from Qwen fragment recovery. Check restored anchor parentheses and newly introduced ellipses at the common cache boundary for every provider, including imported caches. Preserve source punctuation anomalies; never infer that a structural error is a layout overflow.
- Translate plain-language summaries and substantive auxiliary sections in paragraph mode. Publication service metadata, bibliographic citations, author affiliations and figure interiors remain native.
- `run --import-cache-from OLD_RUN` imports compatible, validated paragraph caches into a new run. It compares source identity, native characters, paragraph text and anchor text, records rejected rows, and preserves prior provider evidence. A provider change within an existing run remains forbidden.
- Save `translation_coverage.json` to expose translated and preserved blocks. Machine checks, semantic review, visual review and user acceptance remain separate.
- On unresolved extraction codes in translatable regions, save local 300-dpi crops and OCR suggestions under `local_ocr/`. Use installed Tesseract (English) or macOS Vision via Swift; do not install an engine, upload source text, or automatically rewrite scientific characters. An unavailable engine leaves a diagnostic and blocks unresolved extraction. Source-trace evidence is used before OCR; protected figure interiors are not OCRed.

## Compatibility and limitations

Updated classification can invalidate old paragraph plans. Use a new run with explicit cache import; do not edit old manifests or discard validated translations. The preserved/legacy auxiliary-section policy is unchanged.

Ellipsis and anchor checks catch specific structural failures, not arbitrary semantic omissions. Source-space recovery requires unique glyph evidence; OCR confidence alone never authorizes substitution. Model outputs and crowded layouts still require source-by-source visual and semantic review. Current local OCR covers English source crops; it is not a scanned-document translation engine.

The Wu source PDF and its translations are local validation materials and are not part of the distribution.

## Validation

- 277 local unittest cases passed, including cache handoff interrupted-write recovery, restored-anchor cache invalidation, local OCR crops, narrow sidebar reading order, wide figure-edge captions and acknowledgement/reference separation.
- A local macOS Vision smoke test recognized “Soil moisture changed.” from a rendered crop. OCR suggestions were not applied to source text.
- Wu (2021): the final candidate run exited 0 with 54 validated segments, 12 source and output pages, and no machine QA errors or warnings. Validated caches were reused across explicit new-run imports.
- All twelve candidate pages were visually inspected. The last acknowledgement change altered only page 11, which was inspected again; the remaining page images were byte-identical to the inspected run.
- Known remaining presentation limits: dense fixed formulas on page 3 have uneven wrapping/spacing, long URLs retain native fragments, and some imported Qwen prose remains stylistically awkward. The translation is a review candidate, not a user-accepted or fully semantically certified edition.
- Publication was approved with these known limitations; PDF acceptance remains separate.
