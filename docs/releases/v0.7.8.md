# PaperLocale 0.7.8 — 2026-09-28

本版修复真实论文（DOI: 10.1002/joc.70306）翻译中遇到的三类阻塞，保留原有质量门禁与可恢复断点。

## 修复

- 正确识别 U+00AD 软连字符及其换行续词，保留显式硬连字符、科学减号和原始字形坐标。未知控制字符仍需核对，不能一律删除或猜测。
- 同名嵌入 CFF 字体子集不再仅按字体名称匹配。使用整条源字形轨迹的 Unicode/GID 映射核对；只有唯一字体程序匹配时才恢复行内锚点。同一映射对应不同轮廓时仍拒绝自动选择。
- `the 2019 event` 不再被误判为“2019 个事件”，`second event` 不再被误判为“秒×事件”。年份的数字校验、复数事件数量、事件率以及明确的秒单位/乘积单位继续受检。

## 验证与断点

本地 306 项测试通过；合成论文完整采集、翻译、重建和 QA 流程通过，对照图已检查双栏、公式、表格与图片位置。macOS universal2 构建及签名校验通过。

新增软连字符、未知编码、同名字体子集歧义、日历年份、序数事件和科学单位回归测试。真实 14 页论文已从原断点完成 76 条翻译并正常退出，输出机器 QA 为零错误、零警告；已有合格译文保留。该结果为候选 PDF，不表示逐页人工视觉验收已经完成。

已有已采集断点仍按原版面与内容合同继续；新提取规则不自动重写历史版面计划。需要重新采集时保留旧目录，并在新运行目录通过 `--import-cache-from` 仅复用身份与合同匹配的缓存。

## 下载

命令行安装：`python -m pip install "paperlocale[layout]==0.7.8"`。

macOS 下载：`PaperLocale-0.7.8-macOS-universal2.zip`，支持 macOS 13+、arm64 与 x86_64。App 是 CLI 前端，需要另行安装同版 CLI、Poppler 和已登录的 Codex。仅 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；Intel 未实机验证。详见 [macOS 安装说明](../../macos/README.md)。
