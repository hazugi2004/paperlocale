# PaperLocale 0.8.3

本版修复两篇真实论文暴露的密集图片页、科学上下标、特殊字体编码及链接保留问题，并保留原有内容合同、版面保护和旧断点身份检查。Python 包和 macOS 附件以 [GitHub Release](https://github.com/hazugi2004/paperlocale/releases/tag/v0.8.3) 与 [PyPI](https://pypi.org/project/paperlocale/0.8.3/) 的实际记录为准。

## 本轮修复

- 为密集图片绘制框建立索引，保留原有严格几何容差；对不含 Form 的超密集页面，避免原生文字删除时耗尽图片资源名，不栅格化整页。
- 图片调用计数减少只能在有序非空调用、图像资源及绑定同一源文件、译文和版面计划的保护像素报告共同通过时接受；可见图片删除、绘制换序、透明度变化等反例仍失败。
- 修正作者贡献侧栏分类，重连有几何证据的正文碎片、复合下标及高括号表达式。保留预制 Unicode 上下标字形，让上标引文前的普通正文词进入翻译；旧计划仍按记录的规则重放。
- 为共享同一字体字形的不同字符分别写入 Unicode 映射。仅按已核查的完整 CFF 轮廓恢复特殊括号和误编码小数点，不推测未知字体字形。
- 保留网址中的括号、反斜线和 Unicode，以及跨页分段和间接注释数组中的链接。
- 对同一未修改页面复用文字绘制快照，并为大内容流设置有限、按字节量计算的局部解析预算，保留其他资源上限、完整语法解析和质量门禁。
- 将 layout 依赖约束在 BabelDOC 0.6.x 所需的 bitstring 4.x，并在兼容性检查中实际启动 layout CLI。

## 验证与边界

发布前冻结源码的 534 项本地回归及确定性版面冒烟检查通过。两篇英文主文共 35 页使用 `codex-local / gpt-6-sol / medium` 和 `atmospheric-science` 领域包完成：16 页论文的 76 段、19 页论文的 92 段均无用户跳过，最终机器 QA 错误 0、警告 0，35 页均已逐页视觉复核。16 页论文还使用最终安装版的有序图片与像素联合门禁重跑完整 QA；19 页论文按最终默认提取规则核对正文块、段落组和保护区一致，已完成断点用最终安装版恢复退出 0。完整证据范围见[发布前鲁棒性验证记录](../robustness-20261027.md)。论文、译文、截图和私有日志不随软件分发。

上述验证不能保证任意未知 PDF 均可完成，也不替代逐句专业审校。部分标题与首段连排、局部大数换行和中文措辞仍需人工编辑。`qa_generated` 仍是机器检查候选，不自动写入用户 `accepted` 记录；扫描页、未知字体、复杂旋转正文或无法证明安全的保护边界仍可能明确失败并保存断点。

macOS 应用仍是调用本机 CLI 的前端，需要同版本 Python 包、layout 依赖、Poppler 和所选模型服务。Universal 2 包含 Apple Silicon 与 Intel 二进制；发布前本机启动验证在 Apple Silicon 上完成，Intel 未实机验证。发行使用 ad-hoc 签名，未经 Apple 公证。
