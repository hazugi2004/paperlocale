# PaperLocale 0.7.2

0.7.0/0.7.1 把图注作为保护区，因而没有翻译；固定在原坐标的行内引文与公式又把正文切成多个排字槽，短中文被分散到旧英文行上，造成空洞和碎行。本版新运行默认使用 `paragraph` 模式。

## 段落与图注

- 依据源文首行缩进、行距和标题字重拆分 PDF 原生块中的自然段，保留段落边界。
- 同段跨页、跨栏和绕图时只翻译一次，再将连续词元分配到相应物理框。
- 图注和表注进入翻译；图中文字、表内文字、独立公式、作者/机构、辅助章节及参考文献保留。
- 中文连续排字，移除汉字间非语义空白；保留英文词组和数值单位的空格，不人为拉散短行。

## 行内字形与核验

行内引文和数学内容使用原字体字形、颜色和上下标相对位置，随译文移动；链接目标不变，点击区域同步移动。当前支持水平 Type1/CFF 和 PDF 标准 Base14，未知字体明确报错，不能退化为截图或猜测数学字符。

独立公式和图表保持原位。新坐标的行内字形检查与段落外像素检查分开，不能用旧坐标像素相等冒充文字随动。源文删除、译文回读、科学内容合同、完整候选的原子生成和人工验收边界继续有效。

默认先尝试原字号；必要时每次缩小0.1点，最低为原字号的80%。显式 `--min-font-size` 优先。不能完整容纳则保存断点，不截断内容。旧 `preserved` / `legacy` 运行保持原引擎和缓存；新模式需新运行目录。

## 验证与限制

- 237项测试通过，覆盖原生块内自然段、图注、引文随动与链接、跨页连续性、句读切分及原字形错误拒绝。
- 一篇13页双栏论文完成68个翻译单元、86个物理框，其中17个单元跨框、7个跨页；5条图注全部译出。13页机器QA无错误/警告，全页模型视觉检查通过，并与用户提供的10页WPS版本对照。
- 另一篇既有格式故障论文完成段落计划和删除/字形预检，识别6条图注；未将预检宣称为该篇完整重译。

跨框优先选择附近句读，并避开括号内单位；不改变连续译文内容。保留源段落框会留下比WPS更大的段间留白，字体和行距不保证完全一致。本次开发中修复了原字形资源、回读边界、链接坐标精度和跨栏孤字问题，复用完整译文缓存完成最终输出；不能称为开发全流程首次尝试即成功。自然段识别仍是几何启发式，内容合同也不能独立证明语义准确；不保证未知PDF一次成功。机器与模型视觉复核不替代用户的人工 `accept`。

不公开用户论文、译文、嵌入字体、运行缓存或认证信息。回归PDF由测试生成。

```bash
python -m pip install "paperlocale[layout]==0.7.2"
paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model YOUR_MODEL --reasoning-effort low
```
