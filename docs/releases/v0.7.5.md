# 0.7.5 — 2026-09-22

This patch fixes the Wang (2021) CDHMI regression: partial English italic headings, damaged scientific symbols and fragmented numbered conclusions.

## Changes

- Treat short words in italic prose headings as translatable text. Join adjacent italic heading continuations without absorbing the following body paragraph.
- Keep hanging numbered paragraphs continuous and merge their short final lines into the same physical frame, avoiding large gaps inside a translated list item.
- Recover eleven reviewed publisher symbols only when the embedded CFF outline exactly matches a verified drawing fingerprint. This resolves misleading ToUnicode mappings and misleading glyph names for degrees, arcminutes, comparison signs, minus, multiplication and related symbols. Native character identities and geometry remain available for erasure and preservation checks; replayed symbols retain their original ink and receive correct Unicode copy text.
- Preserve coordinate ranges, signed thresholds, scientific notation and event-rate units as complete scientific expressions. Add event counts and decades to the finite quantity grammar; do not convert values or unit scales.
- Reuse compatible old translations across revised paragraph boundaries only after checking native non-whitespace character geometry, exact source text, anchor semantics and current content contracts. Affected translations are regenerated in a new run; old runs are untouched.

## Limits

The symbol registry is deliberately finite. It does not infer that arbitrary `2`, `8` or `$` characters mean minus, degree or greater-than-or-equal. Unknown outlines are not rewritten, and OCR suggestions do not authorize scientific substitutions. Source-native scientific unit lettering may remain English to preserve the full original expression and superscripts. Figure interiors and standalone equations remain source objects; their existing text mappings are not rewritten by this change.

Existing paragraph plans must be regenerated in a new run with explicit cache import. Machine QA and visual review are separate from user acceptance.

- All 13 output pages were visually inspected. The reported headings are fully translated, coordinates and temperatures retain degree marks, SPEI thresholds and ≥3 retain their signs, trend rates retain negative powers and units, and conclusion items 2 and 3 have no internal frame gaps.
- Separate source paragraph frames still occupy their original positions, so whitespace between different paragraphs remains. This is a targeted symbol/layout repair, not a full stylistic revision of the existing translation. The PDF has not been marked as user-accepted.
