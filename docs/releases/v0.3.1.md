# PaperLocale v0.3.1

v0.3.1 是 v0.3.0 的版面安装兼容性热修复，不改变翻译合同、参考文献默认策略或
运行清单格式。它修复了在干净环境中安装 `paperlocale[layout]` 时出现的确定性
依赖冲突，并把真实兼容性检查重新闭合到逐页 QA。

## 修复内容

- 将直接依赖收敛到已通过真实版面测试、且符合 `pdf2zh-next 2.9.x` 上游约束的
  `PyMuPDF 1.25.2`；
- 合成版面冒烟在 `preserve` 默认策略下显式生成并确认空参考文献映射，若夹具
  意外出现自动参考文献匹配则立即失败；
- `pdf2zh-next --version` 在已观察到的首次冷启动超时后只重试一次，仍要求记录
  实际 CLI 和 BabelDOC 版本；
- PR 测试新增 `[layout]` 依赖求解任务，标签构建也从确切 wheel 复核该 extra，
  避免普通单元测试再次漏掉打包冲突；
- 上游兼容性工作流使用已验证的 Ubuntu 官方软件源，并上传参考文献复核、映射、
  运行清单、逐页 QA 和演示 GIF。
