# PaperLocale 0.5.0

普通 `run` 现在默认修复可确定的源矢量丢失，并在 `preserve` 策略下直接保留
源参考文献版面。用户不必在首次 QA 报错后再补一个隐藏开关。

```bash
python -m paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model gpt-6-astra --reasoning-effort medium \
  --domain atmospheric-science --unattended
```

## 改进

- 矢量恢复最多执行一次，要求源/译 PDF 哈希匹配、只有矢量减少错误，并重新
  通过完整 QA；`--no-restore-source-vectors` 可明确禁用。原开关继续兼容。
- 对象匹配比较实际路径、样式及重复次数，透明度为 0 的对象保持不可见。
  修复须保留文字位置、原有图形及图片内容/位置；QA 统计嵌套 Form 内图形。
- `preserve` 书目采用源字形及区域复制，避免双栏书目重排、混译和重叠。
  相交的破碎单词可纳入区域，但不得碰到源页正文或执行已有删除标注。
  新入口 `restore-reference-layout` 支持已有候选；修复带备份、历史和回滚。
- 修正左栏 References 开始时右栏仍是出版商说明续文的误判，同时保留右栏
  已经是后续书目的期刊布局；长 DOI 页眉不会阻止栏序识别。
- 排版阶段显示开始/完成和日志位置，失败时保留已完成的翻译断点。

## 验证与边界

135 项本地测试通过，包括单栏、双栏、横向版面、真实区域像素相等、跨栏说明、
长 DOI 页眉、重叠文字、透明路径、嵌套图形、删除标注及回滚验证。
两篇既有论文的原始失败候选在隔离运行中使用默认参数恢复到机器 QA 成功，
未重译全文，也未修改另一篇已接受的成果。当前 13 页论文另经逐页视觉复核，
补译被旧规则误保留的说明续文、修正图号错位并完成 `accept`。

现有参考文献片段映射不会被静默改写；旧映射导致的漏译须按实际内容复核。
没有唯一书目标题或越界涉及正文时不猜测、不掩盖错误。扫描件/OCR、复杂公式、
源文字收集不完整及图注公式对象错位仍需专门检查。本版本不保证所有未知版式
均能自动无损完成，也不把机器 QA 当作视觉验收；成功状态仍为 `qa_generated`。
用户论文与私人修复证据不包含在公开制品内。
