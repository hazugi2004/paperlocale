# PaperLocale 0.6.1

修复 Qwen-MT 返回未知、重复或格式改写的保护标记时直接退出的问题。此时整份坏候选作废，并进入已有的单次原文间隙恢复；原文中的标识符在本地原位置保留，不做模糊ID匹配，也不从坏译文补词凑计数。

如果恢复请求仍返回异常保护标记，立即失败并保留断点；不递归重试。分段与整段内容门禁、限流策略及密钥读取保持原有要求。

本补丁的运行逻辑只改 Qwen Provider。Codex/GPT、OpenAI-compatible Provider、共享流水线、合同、排版恢复、QA 和 CLI 的逻辑均与0.6.0逐字节一致；版本号及版本断言例外属于必要发布元数据。160项完整测试通过，包含GPT短键/缓存回归和Qwen异常标记的正反例。

分段修复可能增加调用数并影响流畅度。网络、账户、模型语义和未知版式仍可能触发门禁，候选PDF仍需人工视觉与语义验收。

python -m pip install "paperlocale[layout]==0.6.1"
