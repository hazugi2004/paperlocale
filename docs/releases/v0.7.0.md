# PaperLocale 0.7.0

## 标题、摘要和正文连续翻译

新建运行默认使用源版面模式，将跨页、跨栏和被图片分开的逻辑段落联合翻译，再填回原栏位。仅翻译标题、摘要和正文（含方法）；作者与机构、致谢、作者贡献、利益冲突、资助、数据/代码可用性、参考文献及其他辅助章节连同标题保持原文。后置 Methods 仍属于正文。

图片按实际可见内容及透明蒙版计算占用。删除正文时使用不触及固定字符的局部区域；原图表、图注、公式、引用、链接及页眉页脚由完整保护检查核验。原标题字号与字重保留，中文正文在原区域内重新换行；中文字体、行距和断行不会与英文完全相同。

## 出错保存并等待

`run` 默认保存断点并保持等待。瞬时网络故障最多重试一次，持续错误不反复调用收费模型。外部条件修正后执行 `paperlocale resume-waiting --run-dir RUN_DIR`。已有译文及有界排版精炼结果可以复用；缺段、溢出或保护检查失败时不生成不完整候选。

`--no-wait-on-error` 用于明确需要报错退出的脚本。既有 `--no-contract-repair` 仍默认首错退出，可显式加 `--wait-on-error`。用户取消、断电或操作系统终止不在进程可避免的范围内。

## 验证与边界

- 本地 216 项测试通过，包括跨页绕图、透明孔洞、重叠引用、原生表格/公式、后置 Methods、辅助章节排除、溢出拒绝、等待与恢复。
- 私有真实论文完整 18 页运行正常结束；36 个逻辑段落全部回填，787 个保护区域、所有页面的正文外像素及全文回读检查通过，QA 无错误或警告。
- 非正文检查使用 144 dpi，固定字符按原基线在 288 dpi 比较；这是记录分辨率下的画面一致性证据，不等于 PDF 字节相同。
- Codex 已检查全部页面及正文翻译。该记录属于模型复核，不冒充人工验收；产物仍为 `qa_generated`，`accept` 的人工逐页验收合同保留。
- 不公开真实论文、译文、字体、密钥或本地缓存。自有小型 PDF 在测试时生成。
- 自动分类和阅读顺序仍依赖模型及几何规则。扫描页、旋转正文、不能安全删除或完整容纳译文的未知版式会等待，不宣称任意 PDF 全自动完成。

## 使用

```bash
python -m pip install "paperlocale[layout]==0.7.0"
paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model YOUR_MODEL --reasoning-effort medium
```

还需安装 Poppler。既有运行保持原引擎；新建旧引擎运行使用 `--layout-mode legacy`。详见[源版面与恢复说明](../PRESERVED_LAYOUT.zh-CN.md)。
