# 段落框翻译（0.7.2）

新运行默认采用 `paragraph` 模式。自然段先从原生文本块中按缩进、行距、字号及字重拆出，再建立跨页、跨栏、绕图的逻辑连续关系。每个逻辑段落只翻译一次，每个物理片段保留一个排字框。翻译中的换行不产生新段落。

正文和图注/表注均翻译；图中文字、表内文字、独立公式、作者与机构、辅助章节和参考文献保持原文。短译文从框顶连续排字，不用空格撑满、不把引用前的文字推向旧引用位置。跨物理框按容量分配连续词元。

行内数学与引用保留原字体字形、颜色及上下标相对高度，但坐标随译文移动。当前原字形重排支持已验证的水平 Type1/CFF 及标准 Base14 字体，未知编码明确失败。链接点击区域随锚点移动，目标不变。原图、独立公式和段落区域外像素仍严格核验；移动锚点另核验实际绘制字形、字号、颜色和新位置，不能用旧坐标像素检查冒充。

字号先尝试原字号，必要时以0.1点递减，最低80%；显式 `--min-font-size` 优先。不能完整容纳时保留断点，绝不截断译文。段落检测仍是几何启发式，不保证所有未知PDF正确。

```bash
paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model YOUR_MODEL --reasoning-effort low
```

既有 `preserved`（0.7.0/0.7.1）及 `legacy` 断点不切换引擎；识别计划和缓存身份验证继续有效。要采用新排版请新建运行目录。机器检查与模型视觉复核不等于人工 `accept`。以下保留旧模式的使用与恢复说明。

# 源版面翻译（0.7.0）

本功能已完成一篇 18 页复杂论文和自有回归样例验证。自动分类仍有适用范围，不能保证任意 PDF 都能全自动无损翻译；正式发布状态以 GitHub Release 和 PyPI 为准。

## 运行与恢复

安装 `paperlocale[layout]`，并提供 Poppler 的 `pdftoppm`。新运行默认采用源版面模式：

```bash
paperlocale run paper.pdf --run-dir runs/paper \
  --provider codex-local --model YOUR_MODEL --reasoning-effort medium
```

程序自动取得版面模型和中文字体。也可用 `--font-file` 指定字体；默认保持源正文字号，只有显式提供 `--min-font-size` 才允许缩小。源 PDF、Provider、模型、推理档位、领域包和自动版面计划与断点绑定，恢复时不能混用。

瞬时网络错误最多自动重试一次；其余异常保存到 `waiting.json` 后保持进程存活。外部条件修正后执行：

```bash
paperlocale resume-waiting --run-dir runs/paper
```

恢复信号只对应当次错误，不会接受旧信号。等待期间仅检查本地信号文件，不反复调用收费模型。排版精炼结果也会保存；如果精炼答复漏掉科学标记或破坏锚点括号，可依据明确错误纠正一次，两次答复都保存。纠正后仍不合格则等待，恢复不重复请求。用户取消、电源中断及操作系统终止不属于程序可保证避免的退出。

`--no-wait-on-error` 显式启用报错退出，适合脚本或开发诊断。沿用 0.6.4 的 `--no-contract-repair` 时，默认仍是首错退出；可同时指定 `--wait-on-error` 改为保存后等待。

既有断点继续使用原模式。`--layout-mode legacy` 可明确新建旧引擎运行；它不具备本页描述的源字符删除与保护像素核验。源版面模式要求完整 PDF 和 `preserve` 引用策略。

## 自动处理的范围

只翻译论文标题、摘要和正文（含方法章节）。作者与机构、致谢、作者贡献、利益冲突、资助与伦理声明、数据/代码可用性、参考文献及出版辅助信息连同小标题全部保留原文。章节识别跨页持续生效；参考文献后另列的 Methods 等正文仍参与翻译。

- 逻辑段落与物理文本位置分开保存。同一段可跨页、跨栏或绕过图片，模型接收联合原文，译文写回原位置。
- 同一源文本块里的大号粗体标题与小号正文按字号和字重自动分段，保留标题字号并嵌入中文粗体；不把标题空间借给正文。中文字体不等同于原英文字体。
- 图片占用根据实际绘制记录、变换和透明度蒙版计算；透明孔洞内的正文仍参与翻译。原图像对象保留。
- 图表、图注、参考文献、独立公式和固定引用锚点不进入正文翻译。跨栏图注同时保留；链接框轻微碰到正文词尾不会把词尾字母当成引用，普通可点击说明仍参与翻译。
- 行内变量的基字、下标和帽号整体保护；带数学上标的量值及复合单位使用已有单位解析器确定边界，保持原样。
- 语法明确的括号内统计表达式整体保留。模型同时获得锚点的可见原文说明；译文代回锚点后检查括号配对，避免重复原引用已有的括号。
- 删除框只触及待译字符。引用字框与正文重叠时，寻找不触及保护字符的小区域，并核对原文删除和锚点位置。
- 中文回填使用最终嵌入字体的实际字形边界，避开锚点，处理中文标点换行，并允许在已有范围线/连字符处换行。短译文分配到原段落的行位置，保留跨页/跨栏/绕图两侧的内容；引用前末行在安全范围内靠近原引用。原段落短末行的栏内空白可以使用；候选区域按实际容字数选择。无法容纳时允许同一模型进行一次保持科学内容的精炼。

自动分类和阅读顺序仍依赖模型与几何规则。扫描件、旋转正文、无法证明安全删除或无法容纳完整译文的布局会保存错误并等待，不要求人工改写版面计划，也不会把这种等待记为全自动翻译完成。

## 候选与验收证据

只有所有正文段落通过内容合同、预排版和全文回读后，才原子保存候选 PDF。写入中间文件不会作为候选交付。

`preservation_report.json` 记录源文件、候选、版面计划和嵌入字体证据；逐页比较正文区域以外的画面、保护区、页面几何与链接。图像区域统一在整页 144 dpi 取样，固定字符锚点另以 288 dpi 比较。这证明记录分辨率下的画面一致，不等于原 PDF 字节完全不变。固定锚点按原字符基线分别比较，避免把上标下方的正文空白误计为引用。删除引擎改变的孤立保护区使用源原生片段恢复，保持原隔离色彩组，并在不触及译文时对齐核验像素网格；缺失源矢量按原路径恢复，随后继续执行相同检查。

机器 QA 通过仍为 `qa_generated`。逐页视觉验收和内容核对完成后才可 `accept`；这与人工编辑版面计划是不同步骤。科学合同检查能发现标记、数字、单位等变化，不能独立证明翻译语义完全准确。
