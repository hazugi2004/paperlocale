# PaperLocale 0.6.2

将科学数值和单位作为一个配对对象校验，约束同时适用于 GPT/Codex 和 Qwen。`50 km → 50 千米`、`5 m/s → 5 米/秒` 可以通过；单位遗漏、`500 hPa → 500 Pa`、温标改变及两处量值交换单位都会被拒绝。

实现采用明确登记的 SI 和大气科学单位、中文/英文别名、乘除及整数幂语法，支持范围、科学计数和 `850-hPa` 等文献写法。只规范表示，不做倍率或温标换算；不宣称覆盖所有单位语法。URL、DOI、公式和内部标记仍遵循原有严格门禁。

Qwen 首次请求保留完整量值供自然翻译。若响应不满足门禁，已有的单次原文间隙恢复会在源位置保护完整量值和独立单位，再翻译其余文本；不会向错误译文末尾补单位。恢复仍不合格就保留断点并报告失败，不递归重试。

保护版面占位符拆开的数值小数点及语法明确的整行函数表达式，避免小写变量被译为人名。Qwen 对这种无正文数学片段原样返回，GPT 提示词和共享校验同样要求保留。

新版规则发现旧缓存中的数值和单位错位时，先将原候选及诊断原子归档到 `quantity_cache_rejections.jsonl`，再只重译这些片段。其它缓存门禁错误仍中止；合格缓存继续复用。

GPT 的执行适配器、短键响应 schema 和模型设置保持原样，共享提示词新增原文量值及规范签名。PDF 排版、QA 和视觉验收标准不变。171 项测试通过，覆盖别名、复合单位、前缀/温标错误、单位交换、Qwen 有界恢复及缓存选择性恢复。
