# PaperLocale 0.7.7 — 2026-09-26

本次修复来自 *Critical slowing down of semiarid vegetation resilience is amplified by intensifying heatwaves*（DOI: 10.1038/s41467-026-75130-5）的实际翻译与局部排版问题。

## 修复

- 对已经核对的 AdvMacMthSyN01 减号轮廓恢复 Unicode `−`。只匹配已登记的完整字形轮廓；不全局删除 U+0001，也不把未知控制字符猜成减号。
- 原生行内变量的长上标后出现回退下标时，保留为同一行、同一可移动锚点，避免 `p`、`brown/green`、`r` 与解释正文分裂。原坐标、源字形和上下标相对位置保留。独立公式与图内公式仍受原保护规则约束。
- MuPDF 删除纯填充路径中的零面积贝塞尔段时，不再误判整条路径丢失并重复叠画置信带。描边路径、真正缺失的重复图形与非退化曲线仍正常检测。
- 图表检测框误罩住图注顶部时，只有源对象证据证明重叠条带内不存在图形或非图注文字，才收紧边界。图线或标签仍在条带内时不收紧。
- 找不到 PATH 中的 Codex 时，macOS 会检查用户安装目录和本机 Codex/ChatGPT app 中的可执行文件。显式 `--codex-bin` 和已有 PATH 命令优先，不修改软链接、不自动切换模型。

## 显式省略输出后 QA

`paperlocale run ... --no-qa` 仅适用于 paragraph/preserved 模式。默认仍运行 QA。省略时仍执行生成过程中的内容、覆盖、源对象保护检查，状态保持 `rendered`，候选 PDF 留在运行目录；不伪造 QA/人工验收，也不经由“QA 已通过”的导出通道。之后仍可正常执行 `qa` 与 `accept`。

## 旧断点

已有完整 PDF 可以继续使用。新版段落提取可能改变包含上下标的版面计划，因此不要手工改写旧 `layout_plan.json`。需要重新排版时使用**新的运行目录**并指定 `--import-cache-from <旧运行目录>`；仅复用当前身份和内容合同均匹配的缓存，结构改变的段落会重新翻译。保留原输入和旧输出。

## macOS app 测试版

新增 SwiftUI 原生前端，支持 PDF 选择、Codex 模型/推理档位、开始/继续、日志、结果目录和 QA 开关。下载 `PaperLocale-0.7.7-macOS-universal2.zip`。

这是 **macOS 13+ 的 CLI 前端**，需要另行安装 `paperlocale[layout]==0.7.7`、Poppler 和已登录的 Codex。它不内置 Python/版面模型/凭据。目前只有 ad-hoc 签名，**没有 Developer ID 签名和 Apple 公证**；不是 Mac App Store 发行。包含 arm64 与 x86_64，本次本机运行验证为 Apple Silicon，Intel 未实机验证。安装与限制见 [macOS 说明](../../macos/README.md)。

## 验证范围

新增减号精确匹配、零面积曲线、图注边界、概率变量上下标、Codex 查找和省略 QA 的回归测试。真实论文第 9 页的新提取结果将问题段落合为完整段落，并用已核对译文验证局部排版；未再次调用翻译模型或执行整篇输出后 QA。此版本不宣称所有复杂公式版式均可自动修复。

本地 300 项单元测试通过。macOS 窗口已验证 PDF 选择、显式模型与 QA 参数传递、UTF-8 日志，以及错误/成功退出提示；窗口烟雾测试调用本地领域包校验，不消耗模型额度。
