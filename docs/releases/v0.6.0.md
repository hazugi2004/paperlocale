# PaperLocale 0.6.0

本版本针对真实 Qwen-MT 运行中观察到的兼容问题：PDF 断行网址被自动合并、重复缩写或引文年份被省略、年份与多余数字粘连，以及分段调用触发请求限流。

- URL、公式、数字和科学缩写按出现位置保护，响应还原后执行完整门禁。
- 缺标记或合同失败时，只进行一次原文间隙翻译；标识符由本地在原位置保留。分段失败仍停止，不追加词语凑计数，不切换模型。
- 正常与修复调用共用至少 1.1 秒的请求间隔；明确请求限流最多等待 60 秒重试一次，401 不重试。
- 新增 Qwen 专用 `--api-key-csv`，读取唯一完整字段，避免真实含标点密钥被正则截成短前缀。密钥不会显示或写入运行清单。

分段修复会增加 API 调用，也可能影响流畅度。共享账户配额、网络、模型语义和未知 PDF 版式仍需相应验收；无人值守结果不是自动人工接受。

```bash
python -m pip install "paperlocale[layout]==0.6.0"
paperlocale run paper.pdf --run-dir runs/paper \
  --provider qwen-mt --model qwen-mt-plus \
  --base-url https://YOUR_WORKSPACE.cn-beijing.maas.aliyuncs.com/compatible-mode/v1 \
  --api-key-csv /path/to/key.csv --domain atmospheric-science --unattended
```

官方接口与限制：[Qwen-MT API](https://www.alibabacloud.com/help/en/model-studio/qwen-mt-api)、[限流说明](https://www.alibabacloud.com/help/en/model-studio/rate-limit)。
